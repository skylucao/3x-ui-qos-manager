# IP 归属地（离线参考）

在原 3x-ui 的“网速 / 审计”→“网站连接审计”中，选日期与节点，在公网 IP 下点击 **IP 归属地**。

显示数据库中可用的国家 / 地区、省 / 州、城市、网络运营商和数据库生成日期。缺失字段显示“未知”；无记录、缺少数据库、校验失败和繁忙有各自提示。不是精确定位：这是**连接目标 IP** 的网络归属参考，不是员工所在地，也不能证明具体网站、网页内容或员工活动。CDN、Anycast、云租户、地址转让及陈旧记录可能造成误差。

## 上游与版本

采用 [lionsoul2014/ip2region](https://github.com/lionsoul2014/ip2region) 的 Python 查询库，软件固定在 [v3.17.0 / cd40e3a1d532d645697999d646cf0e10481cef33](https://github.com/lionsoul2014/ip2region/tree/cd40e3a1d532d645697999d646cf0e10481cef33)。官方库支持 IPv4/IPv6，返回国家、省、城市、ISP 与国家代码；数据更新不定期。[上游字段与更新说明](https://github.com/lionsoul2014/ip2region/blob/cd40e3a1d532d645697999d646cf0e10481cef33/README.md)

安装程序直接从该固定提交下载两份官方提供的数据，验证字节数与 SHA-256 后启用，不下载和执行额外代码：

| 数据库 | 字节数 | SHA-256 |
| --- | ---: | --- |
| `data/ip2region_v4.xdb` | 11114380 | `6307a9696f5711f84bcb8b25f07894de68a64a0ed4a1cc7e990562dd3084f210` |
| `data/ip2region_v6.xdb` | 37258897 | `5b93da35ac28bc316dccc54a758381f7a874ae0461dd51ff5df5e34815586f11` |

两份固定文件的头部生成日期为 **2026-07-09 UTC**。这不是查询日期，也不表示所有地址资料都在当日核验过。城市和运营商可能缺失；中国地域字段通常为中文，其他地域通常为英文。

## 隐私与边界

- 归属地操作只查本地文件，不触发 PTR DNS、不访问第三方 IP 查询 API，也不会打开目标网站。现有“反查 IP”按钮仍单独使用服务器 DNS。
- 仍要求 3x-ui 登录态、可信代理、同源与 CSRF 校验，仅允许查询保留期内汇总实际出现的公网单播 IP。拒绝过期、未记录、私有地址、域名或任意 URL；不提供公共 IP 查询接口。
- 归属结果只显示在当前查询响应中，不保存为新的员工记录，不改变域名分类、连接数、使用时长、日报或邮件。不会采集 GPS、Wi-Fi、设备位置、聊天内容或网页正文。
- 数据库位于 `/opt/xray-qos-web/ipdata`，由 root 管理，只读提供给网页服务。文件分次读取，每个请求独立游标；不把约 46.1 MiB 数据同时读进网页内存。[上游并发使用说明](https://github.com/lionsoul2014/ip2region/blob/cd40e3a1d532d645697999d646cf0e10481cef33/binding/python/README.md)
- 日志/日报仍只保留今天和昨天。公开 IP 基础资料库不含本公司的访问历史，不按两天删除；卸载 QoS 时随程序目录移除。

## 安装、修复与升级

v1.3.0 的基础安装器自动安装查询库和已校验数据库；日志采集与邮件仍须另行明确启用。安装下载失败会在改动 3x-ui 前停止；数据库损坏时归属查询显示不可用，不影响 VPN 和限速。

已安装 v1.3.0 的管理员可用以下命令恢复**同一固定版本**的两份数据库（仅访问固定上游文件，不发送访问记录）：

```bash
sudo python3 -B /opt/xray-qos-web/install_ipdata.py
```

程序会核对已有文件，正确文件不重复下载。要更新到更晚的数据，须使用经审查、更新提交及校验值的新项目版本；不会静默跟随上游 master，当前没有自动追新任务。不应手动替换成来源未知的 XDB，校验会拒绝它。
