# Vendored ip2region Python reader

Upstream: https://github.com/lionsoul2014/ip2region

Version v3.17.0, commit cd40e3a1d532d645697999d646cf0e10481cef33.

Source files: binding/python/ip2region/{__init__,searcher,util}.py. Copyright notices are retained. These files are copied with trailing whitespace and final newlines normalized; algorithmic code is unchanged. LICENSE is the Python binding's notice; LICENSE.upstream is the root project's dual Apache-2.0 OR MIT software license.

The IP database is not included or redistributed in this repository. The installer downloads the upstream project's documented sample XDBs directly at the pinned commit; geo_lookup.py records exact byte sizes and SHA-256 hashes. Both database headers have generation date 2026-07-09 UTC. Upstream data updates are irregular. This date is not an assurance that every IP entry was verified on that date.
